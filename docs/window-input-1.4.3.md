# EzGame Blish HUD 1.4.3 窗口与输入改动

交付日期：2026-09-14。基于原 1.4.2 工作树完成研究方案中的两批实现。对应研究见 [窗口与 overlay 研究](window-input-overlay-research.md)。本次只生成本地发布包，未上传线上仓库。

## 已实现

- 以系统前台 HWND 为窗口和输入判断依据；浏览器等外部应用在前台时隐藏 HUD，返回游戏后无激活恢复。最小化、窗口失效或游戏关闭时同步隐藏并撤销输入。
- HUD 按游戏客户区定位，维护与游戏的相对层级；普通游戏窗口对应普通层级，置顶游戏对应置顶层级，恢复时保留既有第三方窗口在 HUD 上方的位置。
- 删除通过额外 Form 包装后 Show 主窗口的旧入口。透明、穿透、不激活样式在服务加载时直接设置，显示统一由窗口状态更新负责。
- 失焦取消点击准备、窗口拖动/缩放、文本选择/按键重复、滑块和滚动条交互。每次返回创建新的输入会话，重新采样物理状态和悬停，不补造按下事件。
- 鼠标按下、释放和滚轮按顺序排队，保留各事件的位置和按钮状态。按住期间的消费归属不因光标移出 HUD 而改变；从游戏开始的手势不能在中途被 HUD 接管。
- 使用系统窗口命中结果让行其他原生 overlay；HUD 自身依靠透明分层窗口的原生命中穿透。该机制不识别注入游戏交换链的第三方 UI。
- 鼠标/键盘钩子在游戏挂接期间保持安装，切前台只更换输入会话，不重排钩子链。安装失败清理部分 hook，修正旧成功结果复用与释放顺序；调试后端使用相同输入许可和队列逻辑。
- 文本转换、控件事件和模块委托在主线程执行；钩子只检查许可、读取捕获快照、维护按键归属和入队。精确修饰键匹配保留，系统切窗组合放行。
- 状态转换日志记录窗口 HWND/PID、显示与输入许可、hook 状态、悬停目标、相机拖动和回调计数，不记录文本内容。

## 验证结果

1. Release / x64 / .NET Framework 4.7.2 构建通过。
2. `tests/WindowInput.ContractTests` 的 13 组行为场景通过：连续事件、首次真实点击、旧会话隔离、拖镜头、消费归属、精确快捷键、系统组合、延迟文本分发、部分 hook 失败与生命周期等。其中原生 Win32 场景实际创建窗口，检查非激活显示、透明命中、其他窗口遮挡、TOPMOST 分组、隐藏与恢复。
3. 完整发布程序用隔离配置启动成功，资源与中文字体加载正常；未运行游戏时 HUD 不可见、输入关闭。
4. 完整程序通过 `--pid` 挂接原生游戏替身，在普通后端和 `--debug` 后端分别验证：前台显示、切到外部窗口后隐藏、切回恢复、最小化隐藏和还原恢复。日志确认 `input=false → true`，后台期间 `hooks=true`，无焦点反复重装。

执行行为测试：

```powershell
dotnet build tests/WindowInput.ContractTests/WindowInput.ContractTests.csproj -c Release
& tests/WindowInput.ContractTests/bin/Release/net472/WindowInput.ContractTests.exe
```

完整程序切窗测试：

```powershell
& tests/WindowInput.ContractTests/bin/Release/net472/WindowInput.ContractTests.exe --smoke "<发布目录>/Blish HUD.exe" "<独立临时目录>"
# 加 --debug 检查调试输入后端；测试会短暂创建原生窗口，并在结束后恢复原前台窗口。
```

测试程序与生产代码共用窗口、事件缓冲及钩子源文件；服务依赖在独立行为测试中被替代。完整程序测试使用实际 exe，没有替换其中的服务。

## 现场验证边界

当前环境未运行真实 GW2，也未取得群友冲突 overlay 的名称、版本及复现过程。因此不将上述结果表述为游戏内 `/wiki` 已实测，也不承诺解决所有第三方注入/光标替换冲突。

拿到实际环境后，优先确认 `/wiki → 浏览器 → Alt+Tab 返回 → 不移动鼠标直接点击 HUD`，以及拖窗、右键转镜头和编辑文本时切走再返回。若仍失效，附对应时间附近的 `Overlay state=` 日志及第三方软件名称/版本，以区分显示、输入许可和钩子链问题。

版本到期时间为北京时间 2026-11-01 00:00。时间校验失败或到期弹窗点击“确定”后，默认浏览器打开 https://ezgame.cc/guides/ezgame-blish-hud-pathing-guide。
